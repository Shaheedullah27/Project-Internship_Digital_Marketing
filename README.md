# FlowDesk — 30-Day Multi-Channel Growth Marketing Campaign

**Digital Marketing Internship Project | Devnexes Digital Solutions**
1-Month Practical Implementation — Domain Track: Digital Marketing

## Project Overview

This repository contains a complete 30-day multi-channel growth marketing campaign strategy built for **FlowDesk**, a fictional AI-powered project management platform for small-to-midsize teams (10–200 employees). The campaign covers customer personas, funnel mapping, a 30-day organic content calendar, paid ad strategy (LinkedIn + Google), a 5-part email nurture sequence, and a full CAC vs. LTV financial model.

**Product concept:** FlowDesk automatically turns team task activity into shareable status reports, eliminating manual status meetings and spreadsheet-based tracking.

## How to Use This Repository

No installation or code execution is required — this is a strategy/planning deliverable, not a software application.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/<your-username>/flowdesk-growth-campaign.git
   cd flowdesk-growth-campaign
   ```
2. **Open the strategy document:**
   Open `FlowDesk_Marketing_Strategy.docx` in Microsoft Word or Google Docs to review personas, funnel mapping, ad campaigns, and email sequence.
3. **Open the spreadsheet model:**
   Open `FlowDesk_Content_Calendar_and_CAC_LTV_Model.xlsx` in Excel or Google Sheets.
   - Go to the **Content Calendar** tab to view all 30 days of scheduled content.
   - Go to the **CAC-LTV Model** tab to review the financial model. Yellow-highlighted cells (blue text) are editable assumptions — change any of them (ad spend, conversion rates, churn, ARPA) and the CAC, LTV, and ratio cells will recalculate automatically.
